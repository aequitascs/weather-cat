# weather-cat
Weather Cat

Weather Cat shows the local forecast as a changing colour and can mirror that
colour to a paired original Yeelight Blue / Blue II bulb.

Serve the project from localhost or HTTPS and open it in a Web Bluetooth-capable
desktop browser. Use **Pair** in the information panel to grant access to a bulb.
The browser remembers the permission and Weather Cat reconnects to the paired
bulb on later visits when possible. Forecast colours are sent at 10% brightness
with the bulb's transition mode fixed to immediate.
